Ramverk: Bootstrap

Om Bootstrap

Bootstrap är ett CSS-ramverk som erbjuder färdiga klasser och komponenter för att enklare kunna bygga webbplatser. Det erbjuder bland annat lösningar för design, navigering, tabeller, formulär och responsiva layouter.

Genom att använda ramverket går det snabbt att skapa grundläggande design utan att behöva skriva all CSS-kod från grunden själv. Bootstrap använder sig av HTML, CSS och Javascript där vissa komponenter som exempelvis responsiv navigering kräver ramverkets Javascript för att fungera.

Mer om Bootstrap finns på deras webbplats:Bootstrap

Fördelar och nackdelar

Fördelar

  • Det går snabbt att förstå och komma igång med färdiga klasser och komponenter.
  • Det finns många inbyggda lösningar för vanliga komponenter som tex navigering, tabeller och formulär.
  • Deras grid system gör det enkelt att skapa responsiva layouter.
  • Dokumentationen innehåller tydliga exempel som gör det lätt att lära och förstå hur komponenterna ska användas.
  • Det går att kombinera Bootstrap med egen CSS för att anpassa utseendet.

Nackdelar

  • Det färdiga utseendet kan ibland vara svårt att anpassa till en helt egen design.
  • HTML-koden kan innehålla många klasser när komponenter byggs upp.
  • Vissa komponenter kräver att man inkluderar Bootstraps JavaScript.

Utvärdering av ramverk

Under arbetet med Bootstrap så har jag framförallt uppskattat deras färdiga lösningar för vanliga komponenter. Det som uppskattades mest var hur snabbt det gick att skapa en responsiv navigering med hamburgermeny som också bara krävde en rad med länkad JavaScript.

När det kommer till friheten för designen så går det att anpassa Bootraps med egen CSS vilket uppskattas då flera färdiga komponenter har en färdig styling som kan vara svår att anpassa till en egen grafisk profil. I denna laboration använde jag dock sparsamt med egen CSS för att testa lägga fokus på hur man kan jobba med dessa färdiga klasser och komponenter.

Dokumentationen var tydlig med hur bland annat tabeller, formulär och knappar kan stylas med deras färdiga klasser, så det var väldigt enkelt att testa sig fram bland dessa utan att det krävdes mycket ändringar i koden.
